# TRADE CARIBBEAN V4.3

**By B2B Dominicana SRL**

## Cambios de V4.3
- Dark Mode neutral carbón/grafito, sin fondo verde, con contraste reforzado en textos, formularios, tablas, navegación y tarjetas.
- Light Mode claro, minimalista y sutil, con tipografía de alto contraste y acentos salvia discretos.
- Selector de apariencia convertido en control moderno de dos botones (Claro/Oscuro), disponible en la barra superior y Configuración.
- Seguro calculado dinámicamente mediante un porcentaje editable aplicado al FOB: `Seguro USD = FOB USD × porcentaje / 100`. El importe calculado alimenta CIF, distribución, impuestos, rentabilidad y reportes.
- El porcentaje inicial es 1.01%, aproximado al importe de seguro que traía la versión anterior para su FOB de ejemplo. Puede cambiarse según la póliza real.

## Uso
Abre `index.html` en un navegador moderno. La aplicación conserva su almacenamiento local y sus tasas editables de simulación.

## Consideraciones
Las tasas de impuestos siguen siendo parámetros de simulación y no constituyen una liquidación oficial de DGA. El seguro se calcula sobre FOB como base operativa configurable; confirma la base y tasa aplicables con la póliza y la documentación aduanera.


## V4.3 — Executive Blue
- Identidad visual Executive Blue aplicada a toda la interfaz: azul marino `#14243A`, azul ejecutivo `#3478D4`, fondos claros `#F5F7FA` y modo oscuro grafito `#15191F`.
- Los informes PDF ejecutivo y técnico utilizan la misma identidad visual en encabezados, indicadores, tablas, totales, acentos y pies de página.
- El flete de Datos Generales del Embarque y el flete de Distribución de Costos ahora se mantienen sincronizados en ambos sentidos; ambos módulos y sus cálculos utilizan el mismo importe.
- Se conservan las funciones y la estructura de navegación de la versión anterior.
